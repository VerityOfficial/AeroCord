# AeroCord

**AeroCord** is a Discord client designed for **Windows 7** and older, dating back to **Windows XP**.

It provides a lightweight way to communicate through Discord on systems where running the modern official Discord client may not be practical.

> ⚠️ **Important:** AeroCord does not provide the same functionality as the official Discord client. Read the limitations and rules below before using it.

## ⚠️ Limitations

Because AeroCord operates through its Discord bot, it has some important limitations.

### Server access

**AeroCord cannot freely join Discord servers like a normal Discord user.**

The AeroCord bot must already be installed in a server before AeroCord can interact with that server.

A server owner or another member with permission to add bots must authorize the AeroCord bot.

Some servers add limitations on the bot. Make sure these 5 settings are enabled for both the bot and the "Communicator" role:
- View Channel
- Read Message History
- Send Messages
- Send Messages in Threads
- Create Public Threads

### ➕ Add AeroCord to your server

**Installation link:**

https://discord.com/oauth2/authorize?client_id=1546017991588581477

The person installing the bot must have permission to add applications/bots to the server.

Discord's bot authorization system requires the bot to be authorized for each server where it will operate.

### Other limitations

Depending on the current AeroCord version, some Discord functionality may not be available, including:

* ❌ Joining servers directly from AeroCord
* ❌ Features that require functionality unavailable through the AeroCord bot
* ❌ Some Discord client settings
* ❌ Some newer Discord features
* ❌ Certain account-management features
* ❌ Features requiring direct access to Discord's normal user client

AeroCord should therefore be considered an **alternative client/interface**, not a complete replacement for the official Discord client.

# 📜 AeroCord Rules

By using AeroCord, you agree to follow these rules.

## 1. Identify yourself in messages

**Every message sent through AeroCord must state the sender's Discord name.**

For example:

```text
[Username] Hello everyone!
```

or:

```text
Username: Hello everyone!
```

This requirement exists because messages sent through AeroCord may be transmitted through the AeroCord bot rather than directly through the normal Discord client.

Do **not** impersonate another Discord user.

---

## 2. No impersonation

Do not intentionally make AeroCord messages appear to have been sent by another person.

You may only identify yourself using your own Discord account name.

---

## 3. Follow server rules

AeroCord users must follow the rules of every Discord server they access.

AeroCord does not give users permission to bypass server moderation, restrictions, bans, or channel permissions.

---

## 4. Do not abuse AeroCord

Do not use AeroCord to:

* Spam messages
* Flood channels
* Abuse bot functionality
* Circumvent moderation
* Evade server bans
* Disrupt servers
* Impersonate other users

---

## 5. Respect moderators

Server moderators and administrators have authority over their servers.

If a server owner removes the AeroCord bot, AeroCord will no longer be able to access that server through the bot.

---

## 6. Respect Discord's rules

AeroCord users must also follow Discord's applicable rules and policies.

Using an alternative client does not exempt a user from Discord's rules.

# 🔒 Privacy & Security

Never give your Discord password, account token, or other authentication credentials to AeroCord or anyone claiming to represent the project.

**Never share a Discord bot token publicly.**

Bot tokens provide authentication as the bot and should be treated like passwords.

   2.5. If you are the server owner, install the AeroCord bot.
3. Open AeroCord.
4. Connect to an available server/channel.
5. **Include your Discord name in every message you send.**
6. Follow the server's rules.
